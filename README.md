# Voice Retrace

話し声の録音から、ノイズや残響を取り除く Mac 用の無料アプリです。
音声修復モデル [Sidon](https://github.com/sarulab-speech/Sidon)（東京大学 猿渡・齋藤研究室 / sarulab-speech、MIT License）を使っています。

- 配布ページ: https://urmasound.github.io/voice-retrace/
- ダウンロード: [Releases](https://github.com/urmasound/voice-retrace/releases)
- 動作環境: Apple Silicon（M1 以降）の Mac、macOS 15 以降

Voice Retrace は URMA Sound が作成した非公式のアプリです。東京大学 猿渡・齋藤研究室、Sidon の作者、Meta、Descript、Hugging Face とは関係がなく、承認・推奨を受けていません。
